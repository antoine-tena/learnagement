# Les décisions

Une décision d'architecture par fichier, `NNNN-titre.md`, jamais réécrite : une décision qui en
remplace une autre est un nouveau fichier qui la cite. Chacune dit le contexte, la décision, ce
qu'elle coûte et les options écartées avec leur raison.

Les décisions encore ouvertes sont dans [architecture.md](../architecture.md), « À décider avec
Flavien ».
